# Stock Lake measurements and sandbox checks

The Ubuntu Lake build covered 72 roots and 140 project modules. It compiled 99 modules from source and checked 9,540 declarations. All 285 ordinary output digests for the 95 edited sources matched the import-table calculation. Across the whole sample, the editor files grew by 1,128 bytes and private files grew by 20,800 bytes. A fresh three-module Lake build took 8.350 → 7.708 seconds elapsed and 15.058 → 14.271 CPU seconds. The candidate was faster in all five measured pairs. For four individual compiler targets, the sum of median elapsed times was 5.470 → 5.230 seconds. Each timed build used a warm-up pair followed by five measured pairs on the same runner. [Original stock build, declarations, comparisons and timing data](https://github.com/aliromman/riemann-hypothesis/tree/f6c3420f029cdcf1274767047e6e2122b945459c/ci/stock-batch-1198/results/45431197871)

The Linux Comparator used its default Bubblewrap sandbox to build four theorem sources, two from each proposal, against their trusted parents. The default and paranoid Lean kernels and nanoda accepted all four proofs. The alternate-proof control passed. Deliberate changes to the statement and permitted axioms produced the expected rejections. [Kernel results, raw exports and controls](https://github.com/aliromman/riemann-hypothesis/tree/ee7f370bbee5adeae169f6d268734be1390cdf0d/ci/source-sandbox/results/45431323026)

A complete ordinary build has nine default targets. A stratified sample of 512 authenticated parent archives contained 1,083,881,126 bytes after extraction. It gives a project-only estimate of 65.63 GiB with an estimated standard error of 2.14 GiB. The default build and complete five-claim sandboxed solution export still require a community run. Full-project build time is unmeasured.
