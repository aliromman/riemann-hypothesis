# Stock builds and proof checks

The ordinary Linux builds and the native comparison used the same published source tree, toolchain and Mathlib pin. The stock job records each source, archive, compiler output, declaration comparison and independent kernel replay. [Source and inputs](https://github.com/aliromman/riemann-hypothesis/tree/f385faa35148d86a9d6541d0c59b174d74baf5e3/ci/stock-batch-1266/results/45446277703) · [Independent public-object readback](bounded-workloads/original-sources.json)

The fresh stock test covered 27 requested roots, 239 project modules and 29 edited files. Lake compiled 36 modules and compared 7,656 declarations. The ordinary public and two IR files matched throughout the panel. Stock Lean replayed six roots. The four-module clean build had median wall times of 11.533 and 11.537 seconds. The sum of six individual source medians went from 26.904 to 26.898 seconds. Eight of those 30 pairs slowed down. [Original observations](https://github.com/aliromman/riemann-hypothesis/tree/f385faa35148d86a9d6541d0c59b174d74baf5e3/ci/stock-batch-1266/results/45446277703)

The normal CLI ran on the complete 59,884-file checkout. A saved 199-clump plan applied in 17.050 seconds on community main and 0.307 seconds with this proposal. Relative to the earlier PR revision on the same checkout, full planning took 19.926 and 18.697 seconds and used 3,744,206,848 and 736,133,120 peak bytes. Each measurement used one warm-up and five scored pairs. Both planners printed identical normal output and produced the same 199 groups of 656 members. The test restored the checkout each time. [Whole-project CLI measurements](https://github.com/aliromman/riemann-hypothesis/tree/21715e52f9d8e4253902b9022d821b1a9ab3135d/ci/clump-cli/results/45446832028) · [All repository tests and four real diagnostic cases](https://github.com/aliromman/riemann-hypothesis/tree/411cc705750daef09bc51cb2b446ea6d97d46e54/ci/clump-diagnostics/results/45448060512)
